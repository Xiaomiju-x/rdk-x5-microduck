# 南瓜面具结构快照

**结项研究选件，原样保留，不是新修图或完整实物认证。** 该结构安装在机器鸭躯干前方，原名称“南瓜精灵胸甲”，与 X5 / 电池背包分开。

每个名称均提供同名 `.step` 与 `.stl`。STEP 便于查看/修改，STL 为当时打印几何。版本和来源 SHA 在 [manifest.json](manifest.json)。本次没有生成新 G-code，也没有发送打印。

| 件名 | 数量 | 用途/版本 |
|---|---:|---|
| P00_fit_gauge | 1 | 相机孔距及灯珠孔试配片，不装到鸭子上 |
| P01_front_collar_R1c_closed_holes | 1 | 前抱箍，采用两个完整封闭孔，替代旧半孔 |
| P02_rear_collar | 1 | 后抱箍 |
| P03_chest_skeleton | 1 | 前骨架，连接面具和托板 |
| P04_pumpkin_imp_shell | 1 | 白色南瓜面具外壳，灯眼/鼻子/声音开口 |
| P05_OV2710_camera_cradle_R1a_header_open | 1 | 相机托架，排针/接口让位修正版 |
| P06_CI1302_R1b_flat_foam_plate | 1 | 语音模块平托板，按当时泡棉粘贴方案保留 |
| P08_LED_keeper_left | 1 | 左灯压片 |
| P08_LED_keeper_right | 1 | 右灯压片 |

旧 P01 半孔前抱箍、P05 未让位版本、P06 原卡边托架和两只 P07 语音隔套未列入本快照。不要按旧整盘工程再混装这些已替代件。

## 安装关系

```text
固定躯干
  └ 前/后抱箍 P01(R1c) + P02
       └ 前骨架 P03
            ├ 相机托架 P05(R1a)
            ├ 语音平托板 P06(R1b)
            └ 南瓜外壳 P04 + 两侧灯压片 P08
```

相机对应“鼻子”，灯珠对应“眼睛”，笑嘴及麦克风开口用于声音路径。面具/抱箍是轻型附件结构，不用来承载电池或主控。这里展示的是结构用途；视觉、语音和灯光完整联动仍未完成。

源结构和旧检查中的相机/模块尺寸、离散姿态及切片时间是当时条件下的参考，不能代替真实插头、线束、装载重量、当前站姿和实物动作的验证。本项目已经停止主动开发，不要求已有实物再拆装或重打。

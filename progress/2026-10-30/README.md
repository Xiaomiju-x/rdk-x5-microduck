# 单电源供电升级进度

## 当前实装：单电源已能站立

RDK X5、单块电池与微雪小板均已安装到鸭子本体，单电源样机已能正常供电、启动和站立。X5背部竖放、单块电池位于其后方框架内，微雪位于上部平台；通信正按40PIN双UART收拢。[当前样机完整说明与正背面照片](../../docs/CURRENT_PROTOTYPE.md)

这组照片记录单电源站立状态；带载行走供电仍在升级。10月23日双电池成功前进视频与其参数作为历史成果继续保留。

## 2026-10-30｜单电源带载问题与新电源采购

此前复用一块成品5V电池，经微雪DC+/DC−同时给RDK X5和15个舵机供电，已完成正常供电、启动和站立；后续带载调试出现供电不足表现：关节跟随无力、复位不到位，部分舵机回报电压降至约3.3～3.4V。能启动不等于能稳定带载。该读数不是X5输入端实测，电池、线束和接头的影响仍需对照确认，不把所有动作问题都归结为电池。

目前已采购高放电能力2S航模电池及配套硬件，预计下周（2026年11月2日至8日）到货并验证，具体以物流为准。本次是正常研发迭代，新方案尚未验证，不宣称已解决带载行走问题。

### 待验证的新供电结构

```text
2S航模电池（满电8.4V）→ T插一分二
  ├→ T插转DC5521 → 微雪Bus Servo Adapter (A) → 15只HD1910M
  └→ 好盈UBEC（输出5.0V）→ RDK X5
```

**更换2S电池前，必须拆除旧的微雪DC+/DC−直供X5连接。2S电压不得直接进入X5的5V针脚或USB-C供电口。** 舵机支路按舵机、小板和线束额定条件核对；UBEC仅给X5降压。5A模块规格不代表一对普通杜邦端子可持续承载5A，输出端子和线径需匹配实际电流。

到货后先核极性、UBEC空载5.0V输出与安装尺寸，再检查X5板端、舵机支路在启动、慢复位及同动作带载时的电压、通信、跟随、温升，随后验证连续运行。充电时电池与鸭子断开。

后续顺序：新电源到货与带载对照 → 按新电池/UBEC尺寸检查轻量支架和关节净空 → 收拢线束 → 复现短距离动作 → 长距离行走与RL闭环验证。已有双电池成功视频、参数及固定Release保留为历史对照，不改写成新单电源成果。

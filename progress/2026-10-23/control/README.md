# 分段颈根与提前收颈：无硬件源码摘录

本目录公开当前D控制器的参数验证与目标计算逻辑。与实机版本的唯一适配是：把原本从内部硬件运行模块导入的11号两个常量（10°旧包络、5计数/拍）写在本文件中，避免导入串口、私有站姿和部署环境。

`duck_tuning_config_20260929.py` 的 `DEFAULTS` 保留历史记录兼容值；**本次演示配置以父目录 `parameters.json` 为准**。它们不是另一台机器的机械标定。

无需硬件或第三方库，在本目录运行：

```sh
python -m unittest test_offline -v
```

测试使用合成START和合成腿目标，只验证11号分段时序、提前1.1秒、其他14轴不变、速度约束与最终回START；不是实机步态、动力学或稳定性验证。这里不提供SSH、串口入口或自动使能，不包含机密校准链、设备序列号、凭据和未经许可的完整CAD/策略权重。许可沿用仓库Apache-2.0，原上游归属见根NOTICE。

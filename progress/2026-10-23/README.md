## 控制方式与冻结配置

本次使用D历史小动作：固定的历史下发目标片段，叠加**仅11号颈根的分段定角与提前收颈**。其余14轴目标及节奏不因颈部微调而改变，不运行全身在线RL策略。

| 控制台项目 | 本次保存值 |
|---|---:|
| 启动颈根角，相对本机START | 0° |
| 走动颈根角，请求值 | 前移30°（代码为−30） |
| 小动作开始后保持 | 0秒 |
| 走动角过渡时间 | 0.2秒 |
| 提前收颈 | 1.1秒 |
| 自动前倾／后倾反馈强度 | 0／0 |
| 反馈上限／死区（强度为0时不产生补偿） | 前后各4°／1° |

[冻结参数JSON](parameters.json) · [新增控制模块与离线测试](control/)

- 正值向后、负值向前是**本台11号实测方向约定**；0°表示已有START目标，不是机械绝对零位。
- 30°是请求值。颈部原有每拍5计数速度约束仍在，短时间内实际或已发送角度可能尚未达到请求值。
- 1.1秒按50Hz轨迹名义时间计算：原第250帧开始的100帧平滑收颈，提前55帧到第195帧。不是瞬间回颈，也不是把原收颈过程压缩成1.1秒；总线耗时可能拉长实际时间。
- 本次两项自动反馈为0，不能将成功归为IMU实时自动纠正。此前全身RL、IMU与关节反馈研究为独立路线。
- 最近同参数程序记录完成400帧、6030次正确回复、0超时/校验错误；程序完成不替代现场效果。录像和日志没有硬件时钟同步，不作逐帧因果断言。

## 工程经验与下一步

关键不只是“把动作幅度调大”，而是把起步、走动、收步所需的身体配合分开处理。这次在能前移的目标片段基础上，仅对颈根角度和提前回位时机做微调，保留了可用的腿部动作；历史失败视频和结构装配记录继续保留在仓库。

接下来巩固固定条件下的重复起停、改善更长距离稳定性，并推进轻量化与V2机内电控集成。本次是原型的功能突破，不是长期可靠性、任意地面或自主导航验收。

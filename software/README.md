# D 短距离前进 · 公开运行包

本次完整方案的推荐软件入口：单一 D 控制台、板端串口运行、400 帧相对轨迹、分段颈部角度、提前收颈、完整单轮与连续 2/3/5 轮、只读检查及托稳慢复位。

**10 月 23 日实机成功的是当时的完整集成与参数。这里的便携运行包从该实现提取，已做离线轨迹、算法和串口目标包对照，未在发布过程中新增实机试跑。** 参数不是所有复刻机器通用的标定值。连续多轮功能已完成软件检查，连续稳定行走仍需实物验证。

## 无硬件快速预览

需要 Python 3.10+。进入本目录，在自己的虚拟环境运行：

```sh
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python runtime.py plan --cycles 5
python app.py --demo --port 9194
```

打开 <http://127.0.0.1:9194/>，顶部显示 **DEMO · 无硬件**。运行、复位按钮仅演示界面，不读取串口、不发送目标。已有程序占用 9194 时，换未占用端口；不要关闭正在使用的实机控制器。

`plan` 只读本地文件，输出 `execute=false`、`motion_writes=0`。5 轮为 2000 帧，每轮名义约 8.23 秒，真实串口开销会增加耗时。

## 板端部署

先阅读 [部署与逐机配置](../DEPLOYMENT.md)。软件直接放在 X5 运行，不需要原开发者的用户名、绝对路径或 SSH 配置，也不需要 ONNX 权重和训练服务器。

```sh
python app.py --robot .local/robot.json --port 9194
```

服务仅监听 `127.0.0.1`。电脑通过 SSH 本地转发：

```sh
ssh -L 9194:127.0.0.1:9194 your_user@your_x5_address
```

再打开电脑的 <http://127.0.0.1:9194/>。本地和板端使用同一个端口；如占用，一起改成同一个空闲端口。本机接口还使用同源检查和每次启动生成的控制令牌，避免第三方网页误发动作请求。

启动服务只载入配置和界面。**运行和复位必须由操作者勾选当轮现场状态并点击对应按钮；只读检查可以单独读取串口，不发运动。** 刷新回单轮，现场勾选清空；保存参数和选轮数不发动作。

## 默认成功参数

|参数|默认值|含义|
|---|---:|---|
|启动角度 `bias_deg`|0°|相对本机 START；正值颈根后移、负值前移|
|走动角度 `motion_deg`|−30°|相对本机 START 的前移请求|
|起步保持 `start_hold_s`|0 秒|腿部动作开始后立即进入颈部平滑过渡|
|过渡 `transition_s`|0.2 秒|从启动角向走动角过渡|
|提前收颈 `return_advance_s`|1.1 秒|相对原收颈时刻提前，按 50 Hz 轨迹时间|
|前倾/后倾反馈增益|0 / 0|成功演示采用分段定角，无自动倾斜反馈叠加|

−30°是请求角，每拍颈部变化速率和提前收颈共同决定实际下发过程，不表示实物一定达到或保持前移 30°。`0°`是真正的本机 START。[默认文件](config/success_20261023.json)。

建议单轮起步，一次只调一项并记录现象。启动前倒可增加正向启动角；走动后倒可增加走动前移；收步前倒可逐步增加提前收颈。提示仅针对已核实的 11 号方向，实际效果取决于装配、载荷和地面。

## 完整周期

150 帧准备 → 100 帧历史小动作 → 100 帧平滑回 START → 50 帧保持。提前收颈可与腿部运动重叠。

连续 2/3/5 轮调用相同完整周期，每轮重新建立 IMU 参考、颈部时钟、20 秒期限和读取重试预算。不会只循环中间 100 帧，不自动开启下一批。操作者停止、通信/失能故障、IMU 停更或一轮不完整，均不继续下一轮。

程序完成只说明目标序列完成和最终目标回到 START；是否站稳、是否前移需现场观察。当前 D 是记录目标序列加颈部调节的过渡方案，非完整全身 RL 闭环。

## 停止与复位

- **停止发目标**：结束当前动作，不进下一轮，保持最后目标，不自动失能或猛拉 START。
- **只读检查**：读取 ID、模式、offset、扭矩、位置、目标、电压，不使能。
- **慢复位**：托稳躯干和头部、双脚卸重。先设刚读到的实际位置为目标，再使能失能关节，随后低速回 START。不改 P/D、offset 或 EEPROM。
- **仅复位可恢复关节**：只处理检查通过、离 START 不超过 512 counts（45°）的关节；其余记入 skipped。部分完成不是整机复位。

故障不自动复位，因为设备失联或姿态不明时无法确认回位路径；先支撑、读取状态，再显式决定复位。

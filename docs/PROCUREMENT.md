# 采购与打印清单：买对一套 RDK X5 Duck

本页面向首次搭建者，配套 [硬件连接](../HARDWARE.md)、[完整装配](../ASSEMBLY.md) 和 [逐步验收表](BUILD_CHECKLIST.md)。资料核对日期：2026-10-27。表中保留10月23日双电池成功样机的采购基线。最新单电池方案已复用现有成品5V舵机电池，从微雪DC+/DC−分供X5和15舵机并正常启动；移除X5专用电池、暂不新增降压模块。带载与连续运行待验证，详见[最新接线与R9](SINGLE_POWER_R9.md)。

### 线束数量怎样来的

第一支路为左腿5只＋头颈嘴5只：1根板端线＋9根舵机间线。第二支路为右腿5只：1根板端线＋4根舵机间线。因此总计15段，不包含USB、IMU排线和两电源线。段数是拓扑计数，接头类型和每段长度依实际走线；不要把两支路末端再跨接成环。

### 工具与辅料

- 与实际螺丝头匹配的小号螺丝刀/内六角、镊子、尖嘴钳、模型剪钳、去支撑工具。
- 卡尺：核对孔、轴承、螺母和电池尺寸；万用表：核对供电极性与电压；秤：记录最终整机及附加件质量。
- PLA、TPU95A HF分别准备；高粘泡棉作固定与消隙，板底另留电气绝缘，不用线缆承重。
- 标签纸标每个舵机ID和打印件号；扎带、柔软束线带及线缆固定点。
- 平整防滑测试面与便于托举的工作区。打印机可自有或外包，不要求购买同型号打印机。

不要打印：旧踝002/004、旧轴承压盖008/065、轮滑支架042/064、轮毂040/060/061/066、轮胎058/087/088/089、轮滑轴承占位063/067。原PCB锁扣006、镜头座025、原电源支架036也不进入这条X5外挂路线；027是**头内电机支架**，必须保留。

本体STL已经选定；本项目3MF提供R8A六件一盘、L2单件替换盘、左右TPU一盘，均需重新切片。整机本体按自己的机器安排盘数；不把P2S原工程直接发给P1S。

## 7. 下单前最后核对

- 舵机外形、主动盘、副盘与FT图纸相符，15只的模式/寄存器版本可识别。
- 两电池分别具有**所需输出接口**；USB-C插孔不必然是输出，DC插得上不必然极性相同。
- 微雪是(A)版，USB数据线能通信；两只D/V/G为同一舵机总线。单电池方案从绿色DC端分供，按专章核对5V、物理针脚、导线与接头，启动验证不代替总负载测试。
- 正常金属轴承、正确牙型螺丝和X5下孔螺母已齐；不可打印轴承代替。
- 用选定STL/清单重新切片，确认最终装载方案没有额外打印一整套旧背包。

厂商资料负责接口规格，本案例负责实际集成路径；没有明示“实测同款”的替代件，均需自行验证。来源与许可见[NOTICE](../NOTICE.md)。
